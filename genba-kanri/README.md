# 現場管理（Gen-Can 現場管理特化版） v1.0.1

Gen-Canのうち **現場管理に必要な機能だけ** を、スマホで使いやすくまとめたアプリです。
**データはGen-Canと共通**（同じGoogle Apps Script・スプレッドシート・Googleドライブ）で、**GAS（サーバー）の変更は不要**です。

- URL：`https://kawaguchidenki001.github.io/genba-projects/genba-kanri/`（GitHub Pagesでmainに反映された後）
- ログイン：Gen-Canと同じID・パスワード。**ログイン状態もGen-Canと共通**（どちらかでログインすれば両方使えます）
- ホーム画面への追加：スマホのブラウザで開いて「ホーム画面に追加」。Gen-Canとは別のアイコン「現場管理」になります

## 画面（下のタブ）

| タブ | できること |
|---|---|
| 今日 | 今日の自分の予定・今日の日報の提出状況・自分が担当の未完了の指摘・進行中の現場 |
| 現場 | 現場一覧（進行中／状態別・検索）、現場詳細、工程表（現場ごとの工程・全現場の工期） |
| 写真 | 小黒板カメラ（黒板を写真に焼き込み）、工種別の写真一覧、写真台帳（PDF／Excel） |
| 日報 | 作業日報（入力・直す・削除）、人員配置（週間ボード・空きマスから配置を追加） |
| 指摘 | 図面（PDF・画像）にピンを立てて指摘・是正を管理、検査（チェックリスト）、印刷・PDF |

## データの保存先（Gen-Canとの対応）

| 機能 | 保存先 | Gen-Canでの見え方 |
|---|---|---|
| 現場 | 案件マスタ（addProject／管理者はupdateProject） | 同じ現場として表示 |
| 工程 | 工程シート（追加＝誰でも、変更・削除＝管理者） | 現場管理の工程に表示 |
| 日報 | 作業日報シート（Gen-Canと同じ人工計算・1日1.5人工の上限・二重登録チェック） | 日報・原価に反映 |
| 人員配置 | スケジュールシートの「担当」 | スケジュール・人員配置ボードに表示 |
| 工事写真 | 現場フォルダ／写真／〈工種〉 | 工事写真・ファイルに表示 |
| 写真台帳 | GASの台帳作成（Gen-Canと同じテンプレート）→ 現場フォルダ／台帳 | 同じ台帳 |
| 図面 | ①現場フォルダ／図面（ドライブで入れたもの）②アプリで追加：現場フォルダ／ファイル（名前の先頭「図面_」・PDFは1ページずつJPEG） | ファイルとして表示 |
| 指摘・対応履歴・検査・検査テンプレート | 現場メモシート（種類＝指摘／指摘履歴／検査／検査テンプレ） | **表示されません**（このアプリ専用） |
| 指摘・検査の写真 | 現場フォルダ／写真／指摘・写真／検査 | 工事写真に表示 |

- 受注金額・実行予算などの金額は、このアプリでは扱いません（Gen-Canで管理者が操作）。
- 日報の「使用材料」（Gen-Can v43.29）はこのアプリでは入力しませんが、**日報を直しても材料は消えずに引き継がれます**。
- 指摘の「対応中・対応済・確認済」は **履歴として追記** します（GASは作成者本人と管理者しかメモを書き換えられないため）。誰がいつ直したかが残ります。
- 「確認済」にできるのは、指摘した人・現場責任者・管理者です。

## ファイル構成

```
genba-kanri/
  index.html      … 画面の枠（ログイン・上のバー・下のタブ）
  app.css         … 見た目
  js/core.js      … 共通（ログイン共有・GAS通信・写真の送信待ち・画面切替）
  js/home.js      … 今日・情報設定
  js/projects.js  … 現場・工程表
  js/photos.js    … 工事写真・小黒板カメラ・写真台帳
  js/reports.js   … 日報・人員配置
  js/issues.js    … 図面・指摘・検査・印刷
  manifest.json / sw.js / icon-*.png … ホーム画面に追加するための設定
  fonts/          … 印刷用フォント（任意。IPAex明朝を置く場所）
```

- 会社名・GASのURLは **Gen-Canの `config.js` をそのまま読み込みます**（このアプリでは書き換えません）。
- 外部から読み込むもの：Googleフォント（画面の文字）、PDF図面を画像にする pdf.js 3.11.174（jsDelivr・改ざん防止のハッシュ付き。PDF図面を開いた時だけ）。

## 更新するとき

1. ファイルを書き換えたら、`js/core.js` の `APP.version` と `GK.CHANGELOG`、`index.html` の `?v=`、`sw.js` の版、各ファイル1行目の版、このREADMEの更新履歴を同じ番号に上げる
2. mainに反映（GitHub Pages）→ スマホでアプリを開き直す（キャッシュしない設計なので、開き直せば新しい版になります）

## 注意

- 電波がない時は保存・読み込みできません（Gen-Canと同じ）。写真の送信中は画面右上に「送信中」が出ます。消えるまでアプリを閉じないでください。
- 印刷（指摘一覧・検査記録）は、印刷画面で「PDFに保存」を選ぶとPDFになります（A4縦）。文字はIPA明朝で表示します。端末にIPA明朝が無い場合は `fonts/README.md` を参照してください。
- 写真台帳のPDF／ExcelはGASがGen-Canの台帳テンプレートから作るため、用紙・書体はテンプレートの設定のとおりです。
