# 印刷用フォント（任意）

このフォルダに **IPAex明朝（ファイル名 `ipaexm.ttf`）** を置くと、指摘一覧・検査記録を印刷（PDF保存）するとき、
端末にIPA明朝が入っていなくても IPAex明朝 で印刷されます。

- 入手先：IPAフォント公式サイト（一般社団法人 文字情報技術促進協議会）の「IPAex明朝」
- 置く場所：`genba-kanri/fonts/ipaexm.ttf`（このREADMEと同じフォルダ）
- ライセンス：IPAフォントライセンスv1.0（再配布する場合はライセンス文も一緒に置いてください）

ファイルを置かない場合は、端末に入っている IPA明朝 → IPAex明朝 → 端末の明朝体 の順で使われます。
