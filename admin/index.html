初期設定ウィザード

導入時に最低限必要な「会社情報・作業員・車両・取引先」を順番に登録します。あとから各マスタ画面で編集できます。

1 会社情報
2 作業員
3 車両
4 取引先
5 完了

1. 会社情報を登録

見積書・請求書に印字される基本情報です。分かる範囲だけ入れて保存できます。

2. 作業員をまとめて追加

1行に1人ずつ入力します。名前だけでも登録できます。ログインID・パスワードを入れる場合はカンマ区切りにしてください。

現在 0 人形式：氏名, 略称, 区分, ログインID, パスワード, 単価

3. 車両をまとめて追加

車両名だけでも登録できます。車検・保険満了日は分かる範囲で入れてください。

現在 0 台形式：車両名, ナンバー, 車検満了日, 保険満了日, メモ

4. 取引先をまとめて追加

取引先名だけでも登録できます。区分は「官公庁・法人・個人」のいずれかを入れてください。未入力時は法人になります。

現在 0 件形式：取引先名, 区分, 電話, 住所, 備考

5. 使い始める

最低限の登録ができたら、現場登録・予定登録・日報入力へ進めます。
