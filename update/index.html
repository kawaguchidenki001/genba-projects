アップデート手順

-

更新作業をこの順番で行うと安全です

GitHub側のファイル更新と、Google Apps Script側のCodeファイル更新は別作業です。特にGASでは古いCodeファイルと新しいCodeファイルを両方残さないようにしてください。

推奨アップデート手順

1
GitHubアップロード用ZIPを解凍ZIPのままではなく、必ず「すべて展開」して中身をアップロードします。
2
GitHubへ一括アップロードGitHubの Add file → Upload files から、解凍した中身を全部ドラッグ&ドロップし、Commit changesを押します。
3
GAS側のCodeファイル名を変更今回のファイル名は - です（config.jsのGAS_FILE欄で管理）。古いCodeファイルは残さず、名前変更して中身を貼り替えるのがおすすめです。
4
GASを新バージョンで再デプロイ保存だけでは反映されません。デプロイを管理 → 既存デプロイを編集 → バージョンを新バージョンにしてデプロイします。
5
ブラウザでCtrl + F5古い画面キャッシュを避けるため、更新後は強制再読み込みします。スマホはブラウザ履歴・サイトデータの削除も有効です。
6
最終チェックを実行運用センターまたは最終チェック画面で、画面バージョンとGASバージョンが一致しているか確認します。

GAS貼り替え時の注意

✓
古いCodeファイルを残さない
古いCodeファイルと新しいCodeファイルを両方置くと、同じ関数が重複してエラーになる可能性があります。
✓
デプロイURLは基本的に変えない
既存デプロイを編集して新バージョンにする場合、GAS_URLは通常そのままで大丈夫です。新規デプロイを作った場合だけconfig.jsのGAS_URL変更が必要です。
