⚡ 現場クイックの使い方

  1. メニューから 現場クイック を開きます。
  2. 現場でよく使う 作業日報・ファイル・工事写真・写真台帳・打刻 を大きいボタンで開けます。
  3. 画面下の固定ナビから、日報・ファイル・写真・打刻へすぐ移動できます。
  4. スマホやタブレットでホーム画面に追加しておくと、現場作業中にすぐ使えます。

📁 ファイルの使い方

  1. メニューから ファイル を開きます。
  2. 公共・法人・個人 などの区分を選びます。
  3. 顧客名を選び、現場名を押します。
  4. Google Driveのように、同じ場所で現場フォルダの中身が開きます。
  5. フォルダを押すと下の階層へ進み、上の階層へ戻る で戻れます。
  6. ファイルを押すとGoogle Drive上のファイルを開けます。
追加ボタンは画面下に固定されています。
読み込みが遅い場合は、画面右上の更新またはブラウザの Ctrl + F5 を試してください。

📸 工事写真の使い方

小黒板カメラメニュー → 工事写真 → 小黒板カメラ。直接カメラを起動し、戻る時は工事写真メニューへ戻ります。
工事写真台帳メニュー → 工事写真 → 工事写真台帳。ファイル画面と同じように現場フォルダを開いて写真を選びます。

📄 工事写真台帳の作成手順

  1. 工事写真台帳を開き、区分 → 顧客 → 現場を選びます。
  2. フォルダ階層を開いて、写真があるフォルダを表示します。
  3. 写真を押すと選択できます。選択順の番号が表示されます。
  4. 拡大 で写真を大きく確認しながら選択できます。
  5. プレビュー・並び替え で出力順を確認・変更します。
  6. 必要に応じて、工種・撮影箇所・備考を入力します。
  7. PDFで作成 または エクセルで作成 を押します。
PCでは写真サムネイルを横6枚で表示します。
フォルダをまたいで写真を選んでも、選択状態は保持されます。
作成済み台帳は、作成済み台帳・台帳フォルダから確認できます。

🧪 デモモードの使い方

  1. ログイン前の画面、またはメニューから デモモード を開きます。
  2. 実際のGoogleスプレッドシートやGoogle Driveには接続せず、サンプル現場で画面説明ができます。
  3. ファイル階層、工事写真台帳、写真選択、PDF/Excel作成の流れをお客様へ安全に見せられます。
  4. 販売説明や社内研修では、実データではなくデモモードを使うのがおすすめです。
デモモードを開く

💴 販売設定の使い方

  1. メニューから 販売設定 を開きます。
  2. 月額料金、初期設定費、サポート範囲、対象外作業を入力します。
  3. 利用規約、プライバシーポリシー、特定商取引法表示の公開URLを登録できます。
  4. 規約プレビュー から、販売用文面のたたき台を確認・コピーできます。
販売設定を開く規約プレビューを開く

🛠 困った時の確認

ログインできない確認
スプレッドシートの作業員マスタで、ログインID・パスワード・パスワードハッシュを確認します。
通信エラーGAS
GASを保存後、既存デプロイを新バージョンで再デプロイしているか確認します。
画面が古いキャッシュ
Ctrl + F5 で強制更新し、バージョンバッジを確認します。
ファイルが開かないDrive
Google Driveのフォルダ権限、GAS実行ユーザー、Drive親フォルダを確認します。
初期設定チェックで確認 バージョン確認へ

エラー診断・サポート依頼

通信エラー、GAS未更新、Drive権限、シート不足、ログインセッション切れをまとめて確認できます。

エラー診断・サポート依頼を開く

バックアップ・復元

管理者はメニューの「バックアップ・復元」から、今すぐバックアップ、自動バックアップON/OFF、オフライン版の作成、バックアップ一覧確認ができます。復元するときは、先に現在のDBをバックアップし、必要なシート・行だけコピーしてください。

バックアップ画面へ

最終チェック画面

更新後の確認メニュー → 最終チェックで、GAS接続、主要画面、バージョン反映をまとめて確認できます。
表示がおかしい場合最終チェックの「画面キャッシュ削除」を実行してから、Ctrl + F5で再読み込みしてください。
